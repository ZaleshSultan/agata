# 🌹 Агата — Локальный Голосовой Ассистент на Python

**Агата** — персональный голосовой ассистент с полноценным **Agent loop**, трёхуровневой системой памяти ("второй мозг") и выраженным характером (утончённая, ироничная, с чувством драмы). Работает полностью локально через Ollama, без Docker, Redis и облачных API.

---

## 🌟 Архитектура

1. **Agent Loop с Tool Calling**
   - Нет жёстких `if/else` роутеров — модель Qwen3 самa принимает решение о вызове инструментов на основе их JSON Schema.
   - Поддерживает безопасный цикл взаимодействия (обратная связь инструментов через сообщения `role="tool"`).
   - Инструменты с побочными эффектами (например, создание напоминаний) запрашивают подтверждение пользователя в консоли (`requires_confirmation = True`).

2. **Трёхуровневая Память ("Второй мозг")**
   - **Рабочая память (`working_memory.md`)**: Краткосрочный контекст пользователя и активные задачи (всегда встроен в системный промпт).
   - **Долгосрочный дневник (`agata.db`)**: SQLite с вектором эмбеддингов (`nomic-embed-text`) для семантического поиска воспоминаний по косинусной схожести.
   - **Процесс консолидации ("Сон")**: Скрипт `scripts/consolidate.py` периодически объединяет похожие записи в дневнике и актуализирует рабочую память через LLM.

3. **Офлайн STT / TTS Пайплайн**
   - **STT**: `faster-whisper` (модель `small`, ускорение на NVIDIA GPU через CUDA) + VAD (детекция тишины по амплитуде через `sounddevice`).
   - **TTS**: Локальный Neural TTS backend на базе **Coqui XTTS-v2** с **zero-shot voice cloning** по короткому образцу речи + автоматический fallback на `pyttsx3` (Windows SAPI5).

## 🎙️ Voice / TTS (Клонирование голоса)

Агата поддерживает **zero-shot voice cloning** через модель Coqui XTTS-v2.

### 1. Установка зависимостей
```bash
pip install coqui-tts soundfile
```

### 2. Размещение reference audio
Поместите файл с образцом голоса (WAV, 6–15 секунд чистой речи) в папку `voices/`:
```text
voices/agata_reference.wav
```
*Инструкцию и рекомендации по подготовке аудио см. в `voices/README.md`.*

### 3. Конфигурация (`config.py`)
```python
TTS_ENGINE = "xtts"             # "xtts" (основной) или "pyttsx3" (fallback)
TTS_DEVICE = "auto"             # "auto", "cuda" или "cpu"
TTS_LANGUAGE = "ru"             # Язык синтеза
TTS_VOICE_PATH = "voices/agata_reference.wav"
```

### 4. Выбор CUDA/CPU и Fallback
- При наличии GPU (NVIDIA RTX) модель использует **CUDA** в режиме `float16`.
- Если GPU недоступен или reference audio не найден / повреждён, система **автоматически переключается на pyttsx3** без остановки работы Агаты.

### 5. Диагностика
Для проверки готовности TTS подсистемы выполните:
```bash
python scripts/tts_diagnostics.py
```

### 6. Безопасность
> **Важно**: Функция клонирования голоса должна использоваться только с согласия и разрешения владельца/носителя голоса.

## 🛠️ Шаги установки и настройки

### 1. Требования к окружению
- **ОС**: Windows 10/11
- **Python**: 3.11+
- **Ollama**: Установлена и запущена (`http://localhost:11434`)

### 2. Установка Python-зависимостей

```bash
pip install -r requirements.txt
```

### 3. Подготовка моделей Ollama

Скачайте бановую модель LLM и модель эмбеддингов:

```bash
ollama pull huihui_ai/qwen3-abliterated:30b-a3b
ollama pull nomic-embed-text
```

Создайте пользовательскую модель `agata` с зашитым характером из файлу `Modelfile`:

```bash
ollama create agata -f Modelfile
```

## 🚀 Запуск

### Запуск голосового ассистента

```bash
python main.py
```

- Нажмите **ENTER**, чтобы начать говорить в микрофон (запись автоматически остановится при наступлении тишины).
- Либо введите текст вручную в консоли для отладки.

### Запуск консолидации памяти ("Сон")

Чтобы сжать накопившиеся записи дневника за последние дни и обновить рабочую память:

```bash
python scripts/consolidate.py
```

## 🔧 Как добавить новый инструмент (Tool)

1. Создайте модуль в папке `tools/` (например, `tools/weather.py`):
   ```python
   def get_weather(city: str) -> str:
       return f"В городе {city} сейчас отлично."

   TOOL_DEFINITION = {
       "function": {
           "name": "get_weather",
           "description": "Получить погоду в городе.",
           "parameters": {
               "type": "object",
               "properties": {
                   "city": {"type": "string", "description": "Название города"}
               },
               "required": ["city"]
           }
       },
       "requires_confirmation": False
   }
   ```
2. Зарегистрируйте инструмент в `tools/__init__.py` в словаре `_REGISTRY`.

## 🔒 Известные ограничения безопасности

- Агата НЕ имеет доступа к произвольному выполнению команд или файловой системе.
- Системный контроль ограничен явным белым списком: открытие браузера/URL,
  запуск приложений из ALLOWED_APPS (tools/system_control.py), копирование
  проекта на съёмные диски.
- Чтобы добавить новое приложение в белый список — вручную отредактируй
  ALLOWED_APPS в tools/system_control.py. Через голосовую команду список
  расширить нельзя — это осознанное архитектурное ограничение.

## ⚠️ Известные ограничения MVP

1. **Бинарный VAD по амплитуде**: Простой аудио-порог тишины в `stt.py` может реагировать на фоновый шум.
2. **Одиночные побочные эффекты**: Напоминания сохраняются в SQLite, но фоновый сервис уведомлений в рамках данного MVP вызывается по команде (инструмент `list_reminders`).
3. **Русский голос TTS**: Качество речи в `pyttsx3` зависит от установленных в вашей системе Windows системных голосов (рекомендуется голос "Ирина" / Microsoft Irina).
