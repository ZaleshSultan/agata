# AGATA Fine-Tuning v2: характер + знания

Этот эксперимент дополняет предыдущий набор и **не изменяет GitHub AGATA / Ollama**.

## Задача
Проверить, сможет ли LoRA/SFT на компактной Qwen выучить *узкие статические знания* из примеров диалогов, помимо личности Агаты.

## Что входит
- `dataset/train.jsonl`: 106 диалогов, в том числе 60 новых примеров о проекте AGATA, Linux/сетях/SQL и корректном использовании инструментов.
- `dataset/eval.jsonl`: прежняя проверка тона.
- `dataset/knowledge_benchmark.jsonl`: 22 новых **необучающих** перефразированных вопросов, плюс вопросы на неопределённость.
- `train_agata.py`: попытка LoRA на `Qwen/Qwen3.5-0.8B`; скрипт запускается отдельно, исходный репозиторий не затрагивается.
- `benchmark_knowledge.py`: сравнение базовой и дообученной модели на одинаковых вопросах.

Факты про AGATA основаны на просмотренных `Modelfile`, `prompts.py`, `config.py`, `agent.py`, `llm.py` из GitHub `ZaleshSultan/agata` (ветка `main` на 2026-11-10). **Если код изменится, факты могут устареть.**

## Запуск
В подготовленном CUDA-окружении с Unsloth, datasets, TRL, PEFT:

```powershell
python benchmark_knowledge.py            # базовый результат
python test_agata.py                     # стиль базовой модели
python train_agata.py                    # обучаем LoRA
python benchmark_knowledge.py --adapter  # знания после обучения
python test_agata.py --adapter           # стиль после обучения
```

`outputs/agata_lora` содержит адаптер. Исходный Ollama `agata` не заменяется. Если GPU переполнится, сначала уменьшите `SEQ_LEN` до 256 или training set; обязательно закрывайте Ollama и Whisper/XTTS перед обучением.

**Только ключевые слова не доказывают корректность.** Внимательно прочитайте все ответы, особенно отрицательные и вопросы про вызовы инструментов. Для убедительного результата важны ответы на перефразировки и сравнение до/после при одинаковых условиях. Обучение одной и той же небольшой подборкой может привести к переобучению.

## Ограничения
- Этот набор **не исполнялся на RTX 4050**. Версии Unsloth/TRL меняются; могут понадобиться правки.
- LoRA **не гарантирует** долговременную точность фактов и не заменяет RAG/память для новых данных.
- Не добавляйте пароли, токены, личные переписки и другие секреты в обучающий датасет.
- Предназначено для учебного эксперимента, а не для принятия решений на основе единственного ответа модели.
