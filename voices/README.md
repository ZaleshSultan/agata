# Reference Voice для Агаты

Поместите сюда WAV-файл с reference голосом для voice cloning.

## Требования к файлу

- **Формат**: WAV (PCM)
- **Каналы**: моно (1 канал) — рекомендуется
- **Sample rate**: 22050 Hz — рекомендуется (XTTS автоматически ресемплит)
- **Длительность**: 6–15 секунд чистой речи
- **Качество**: без фонового шума, музыки, эха
- **Содержание**: естественная разговорная речь на русском языке

## Имя файла по умолчанию

```
agata_reference.wav
```

Путь настраивается в `config.py` → `TTS_VOICE_PATH`.

## Безопасность

Voice cloning воспроизводит характеристики голоса реального человека.
Используйте только голос, на использование которого вы имеете разрешение
от его носителя/правообладателя.
